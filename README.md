# SC Dandiya 2026 - Street Cause Dandiya Management Hub

Automated Razorpay Ingestion, Google Sheets Sync, and Pass/Donation Management for Street Cause Dandiya 2026.

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
